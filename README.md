# 韭菜王

在 VS Code / Cursor 的状态栏和侧边栏查看股票与可转债行情。自选列表和状态栏的常规行情来自新浪财经，开盘集合竞价参考价由东方财富行情补充。9:15–9:25 展示竞价参考价，9:25–9:30 保留开盘竞价结果，连续竞价展示实时价，收盘后继续展示最近收盘价和当日涨跌。

点击自选列表中的证券或状态栏行情，可打开纯行情详情页，查看分时、五日、日 K、周 K、月 K 和 5 分钟 K 线。日/周/月/5 分钟 K 线下方可切换 MACD、KDJ、RSI 和 MOM 动量副图，指标会跟随日期选区和悬浮十字线同步，并给出动量强弱提示。详情页顶部显示交易状态与北京时间，并以三列摘要展示今开、昨收、换手率、最高、最低、市盈率 TTM、成交量、成交额和总市值。详情页使用东方财富 JSON 行情自行绘制并每 10 秒刷新；当日分时横轴固定补全到 15:00，分时和 K 线均支持纵横指示线、轴边数值、曲线交点及详细数据浮层。页面不包含置顶、监控价格、编辑、买卖、删除或旧走势图切换按钮。

## 使用

1. 点击活动栏中的折线图图标打开“自选股”，现有证券会显示在默认的“我的自选”分组中。
2. 视图右上角的 `+` 默认把搜索到的股票/可转债加入“我的自选”。每个分组标题右侧也有 `+`，点击后搜索并直接加入该分组。
3. 点击视图右上角的新建文件夹按钮可创建分组。右键分组也可选择“添加股票”；右键已有证券选择“添加到分组…”，或直接拖到目标分组。
4. 点击证券条目本身打开实时分时/K 线详情；点击条目右侧的图钉按钮，可将其固定到状态栏或取消固定，最多同时固定 5 个。点击任一状态栏行情也会打开该证券详情。
5. 各分组内都支持拖拽排序；右键菜单保留了向上/向下移动、置顶、置底和删除。右键自定义分组可删除分组。

默认每 3 秒刷新，可在设置中修改 `韭菜王: Refresh Interval`。代码会自动推断市场：`6/5/9` 开头的股票以及 `110/111/113/118` 开头的可转债为上海，`0/1/2/3` 开头的股票及其他可转债为深圳，`4/8` 开头为北京。

> 行情数据仅供参考，不构成投资建议。公开接口可能调整或限制访问，使用时请遵守数据提供方条款。

## 开发

```bash
npm install
npm run compile
```

在 VS Code 中按 `F5` 启动 Extension Development Host。
